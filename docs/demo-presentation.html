创新性

两端一体，全新切入

传统美甲平台解决的是「展示」问题，Nails-Agent 解决的是「决策」和「运营效率」问题。 C端消除选择焦虑，B端消除运营人力依赖。

C 端用户体验 Consumer

用户从「看图猜效果」升级为「上传手图，试戴后决策」。同时基于手型识别匹配相似用户偏好，推荐更精准。

1
浏览 Agent 实时维护的主推荐页
2
上传手图 → 手型 + 肤色识别
3
相似手型用户的热门款推荐
4
一键试戴，30 秒出效果图
5
收藏 / 跳转预约下单

B 端智能运营 Business

每 12 小时自动运行一轮 Agent：聚合行为热度，识别机会与异常，自动调整推荐位与候选款上下架，将每次决策效果复盘为可复用经验。

1
聚合行为事件 → style_heat / tag_heat
2
识别机会 / 异常 / 趋势 / 候选匹配
3
执行决策：推荐调整 / 上下架 / 实验
4
原子切换推荐快照，避免半更新
5
复盘 → 写入 strategy_memories
核心创新点：「相似手型推荐」基于真实手型+肤色匹配，不是猜你喜欢而是找和你长得像的人在选什么。 Agent 的 strategy_memories 机制让系统在每轮决策后自我更新经验库，越跑越聪明。

完整性 · 技术成熟度

技术架构纵深

Next.js 全栈 + LangGraph.js Agent + ComfyCloud，轻量部署，完整功能覆盖。

前端 + 后端
Next.js 14
App Router + TypeScript。C端 / B端同构，API Routes 处理所有后端逻辑。
Agent 框架
LangGraph.js
图结构 Agent，支持条件分支（warmup 检测 / 决策分叉）和状态持久化。接 Qwen via ModelScope。
试戴管线
ComfyCloud + Nano Banana 2
GeminiImage2Node 工作流：LoadImage×2 → ImageBatch → 生成 → SaveImage。100% 成功率。
视觉特征提取
Roboflow API
98 款美甲的颜色族 / 主色 RGB / 长度比例结构化提取，支撑精准推荐和 Agent 分析。
数据层
SQLite + Drizzle ORM
21 张表，本地运行零配置。推荐快照原子切换，保证前端始终读到完整状态。
部署
pnpm dev + ngrok
演示环境一条命令启动，ngrok 提供公网访问。无需云服务器，评委可直接访问。
