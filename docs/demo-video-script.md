# Nails-Agent 演示视频：全链路录屏操作与逐字稿对照表 (V3.0 - 比赛决赛版)

本方案涵盖了 C 端用户决策链路与 B 端智能运营 Agent 闭环，支持 Markdown 渲染展示。

| 阶段 | 页面 | 录屏操作 (Action) | 讲解词 (口语化/去AI味) | 预估时长 | 字数 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1. 开场** | **C端首页** | 停留在首页，鼠标滑动展示美甲瀑布流。 | 大家好，这是 Nails-Agent。在美甲市场，用户常面临“图片好看但戴上不准”的痛点，商家则苦于运营低效。我们用 Agent 彻底打通了这个闭环。 | 15s | 70 |
| **2. 分析** | **上传页** | 点击上传手图，展示 CV 自动提取手型和肤色的过程。 | 上传手图后，系统通过计算机视觉自动识别手型与肤色，并写入 `user_hand_profiles`。这是精准推荐的底座。 | 12s | 75 |
| **3. 创新推荐** | **推荐弹窗** | 弹出“相似手型推荐”，展示根据手型匹配的结果。 | 不同于传统的“猜你喜欢”，我们核心创新是“相似手型推荐”：找跟你手型长得像的人在选什么，转化率直接提升。 | 15s | 80 |
| **4. 极致试戴** | **详情页** | 点击“立即试戴”，展示 Loading 并展示最终高清结果图。 | 点击试戴，调用 ComfyCloud 运行 FLUX.2 Klein 和 Nano Banana 2 模型。30秒内，用户就能看到真实佩戴效果。 | 18s | 85 |
| **5. B端监控** | **B端看板** | 切换到后台，鼠标滑过 Heat Score 排名和趋势图。 | 视角转到 B 端。运营 Agent 实时监控款式热度，计算 Heat Score。你可以清晰看到哪些款式正在走红，哪些正在掉队。 | 15s | 80 |
| **6. Agent决策** | **B端看板** | 点击“运行下一轮”，展示 Agent 正在生成的 Decision List。 | 点击“运行下一轮”，Agent 用 LangGraph 自动执行决策：提权潜力款、下架冷门款。所有动作自动闭环，无需人工盯盘。 | 18s | 90 |
| **7. 语义播报** | **B端 Chat** | **点击右侧 Chat，展示渲染后的 Markdown 结构化摘要。** | Agent 还会生成结构化的自然语言播报。得益于 Markdown 渲染，运营人员一眼就能看清本轮“发现了什么、做了什么、为什么”。 | 15s | 85 |
| **8. 经验学习** | **Memories** | 切换到策略记忆页，展示历史复盘结论。 | 最硬核的是策略记忆。Agent 会复盘每次动作的效果并写入经验库。系统在运营中持续学习，像老司机一样不断进化。 | 12s | 75 |
| **9. 结语** | **技术汇总** | 快切 21 张表 ERD 架构图和 100 张成品试戴图总览。 | 21 张表打通 C+B 链路，100% 试戴成功率。Nails-Agent，让每一个用户在选择之前，就看见答案。 | 10s | 55 |

### **总计参考：**
*   **总时长：** 约 2 分 10 秒 (130秒)
*   **总字数：** 约 695 字
*   **平均语速：** 5.3 字/秒 (专业路演语速)

### **录制建议：**
1.  **重点展示渲染**：在步骤 7 中，务必展示右侧 Chat 栏里的加粗标题和列表，这是展示“工程完备性”的加分项。
2.  **数据真实感**：录制前确保数据库中有几条历史 Run 记录，让时间轴（Timeline）看起来是有积淀的。
3.  **转场**：从 C 端切 B 端时，建议加一个“Admin Access”的转场特效。
